Cara kerjanya

Empat langkah. Setelah ekstensi terpasang, kamu cukup mengulang langkah 3 dan 4 setiap kali ada logbook baru.

Isi template

Satu baris Excel untuk satu log: tanggal, jam, lokasi, keterangan, dan nama file foto.

Pasang ekstensi

Cukup sekali. Ekstensi hanya aktif di halaman Log Aktivitas Student Portal.

Buka Log Aktivitas

Login seperti biasa, buka Log aktivitas yang masih Draft, lalu klik tombol ⚡.

Cek lalu kirim

Pilih Excel dan foto, periksa pratinjaunya, lalu kirim. Progres tampil per baris.

Panduan lengkap

Ikuti urutannya. Kalau bingung di satu langkah, lihat bagian FAQ di bawah.

1

Buat aktivitas di Student Portal

Logbook hanya bisa ditambahkan ke aktivitas yang sudah dibuat dan masih berstatus Draft.

  1. Login ke studentportal.ipb.ac.id.
  2. Buka menu Kemahasiswaan → Aktivitas.
  3. Klik + Non-Kompetisi (untuk MPKMB/ospek/pelatihan) atau + Kompetisi (untuk lomba), isi datanya, lalu Simpan Draft.
2

Download dan isi template Excel

Isi sheet Logbook. Sheet Contoh dan Petunjuk hanya sebagai panduan dan tidak ikut dikirim.

  • Simpan semua foto bukti di satu folder.
  • Tulis nama file fotonya di kolom Nama File Bukti, persis seperti di laptop (misalnya hari1.jpg).
Download Template Excel
💡 Bisa juga diisi di Google Sheets. Setelah selesai, pilih File → Download → Microsoft Excel (.xlsx).
3

Pasang ekstensi di Chrome (cukup sekali)

  1. Download autokonvert-extension.zip, lalu klik kanan → Extract All. Simpan foldernya di tempat yang tidak akan dihapus, misalnya Documents.
  2. Buka Chrome, ketik chrome://extensions di kolom alamat, lalu tekan Enter.
  3. Nyalakan Developer mode di pojok kanan atas.
  4. Klik Load unpacked, lalu pilih folder autokonvert-extension hasil extract (folder yang berisi file manifest.json).
  5. Ekstensi AutoKonvert Logbook IPB muncul. Klik ikon puzzle 🧩 di toolbar lalu pin ⚡ agar mudah ditemukan.
Download Ekstensi (.zip)
⚠️ Jangan hapus atau pindahkan folder ekstensi setelah dipasang, karena ekstensinya akan berhenti bekerja. Ekstensi ini juga bisa dipakai di Microsoft Edge (edge://extensions) dan Brave.
4

Kirim logbook otomatis

  1. Di Student Portal, buka Aktivitas lalu klik tombol Log (ikon daftar) pada aktivitas Draft.
  2. Klik tombol ⚡ AutoKonvert Logbook di pojok kanan bawah.
  3. Pilih Excel, lalu Pilih Foto. Di jendela pilih file, buka folder foto dan tekan Ctrl+A untuk memilih semuanya.
  4. Centang Dosen Penggerak, lalu cek tabel pratinjau. Baris merah perlu diperbaiki di Excel dulu.
  5. Klik Kirim. Tunggu sampai selesai, lalu klik Muat ulang halaman untuk melihat hasilnya.
✅ Log yang sudah ada di portal (tanggal dan jam mulai sama) otomatis dilewati, jadi aman kalau kamu mengirim ulang file yang sama.

Pakai di iPhone

Chrome di HP tidak bisa memasang ekstensi. Di iPhone, AutoKonvert berjalan di Safari lewat aplikasi gratis Userscripts. Fiturnya sama dengan versi laptop, termasuk foto dari Google Drive.

1

Pasang aplikasi Userscripts

  1. Unduh Userscripts dari App Store (gratis). Butuh iOS 15.1 atau lebih baru.
  2. Buka aplikasinya sekali, lalu ikuti petunjuk untuk memilih folder penyimpanan script. Folder bawaan sudah cukup.
  3. Buka Pengaturan → Safari → Ekstensi (di iOS 18: Pengaturan → Apps → Safari → Ekstensi), lalu aktifkan Userscripts.
  4. Pada bagian izin situs, izinkan studentportal.ipb.ac.id dan drive.google.com, atau pilih Izinkan untuk semua situs.
2

Pasang script AutoKonvert

  1. Buka halaman ini di Safari iPhone, lalu ketuk tombol di bawah.
  2. Akan muncul halaman berisi kode. Ketuk ikon ekstensi di kolom alamat (ikon puzzle 🧩 atau AA), pilih Userscripts, lalu ketuk Install.
Pasang di iPhone (userscript)
💡 Kalau tombol Install tidak muncul, simpan filenya dulu: tekan lama tombol di atas, pilih Unduh File Tertaut, lalu pindahkan autokonvert.user.js dari aplikasi Files ke folder Userscripts.
3

Pakai di Student Portal

  1. Di Safari, login ke Student Portal dan buka Log aktivitas berstatus Draft.
  2. Ketuk tombol ⚡ AutoKonvert Logbook di bagian bawah layar.
  3. Pilih Excel dari aplikasi Files. Kalau logbook ada di Google Sheets, buka di aplikasi Google Sheets lalu pilih Bagikan & ekspor → Simpan sebagai → Excel.
  4. Foto dari link Google Drive diambil otomatis. Untuk baris lain, ketuk Dari HP untuk memilih foto dari galeri (foto HEIC iPhone otomatis diubah ke JPG).
  5. Cek kartu-kartu pratinjau, lalu ketuk Kirim.
⚠️ Biarkan Safari tetap terbuka dan layar menyala sampai semua log selesai terkirim.

Urutan kolom boleh berbeda, asalkan judul kolomnya sama. Baris kosong dan baris TOTAL dilewati.

Isian Online, Zoom Meeting di satu kolom otomatis dipisah menjadi tipe dan lokasi. Pertanyaan umum

Belum terjawab? Cek dulu pesan error di tabel pratinjau. Biasanya penyebabnya tertulis di sana.

Apakah akun dan password saya aman?

Ya. Kamu login sendiri di Student Portal seperti biasa. Ekstensi hanya bekerja di halaman Log Aktivitas dan memakai sesi login yang sudah ada. Tidak ada password, cookie, atau data yang dikirim ke server lain selain Student Portal.

Tombol ⚡ AutoKonvert tidak muncul.
  • Pastikan kamu berada di halaman Log Aktivitas (alamatnya mengandung LogAktivitasKampusMerdeka), bukan di daftar Aktivitas.
  • Pastikan ekstensi aktif di chrome://extensions, lalu muat ulang halaman dengan F5.
Muncul pesan "Log aktivitas ini tidak bisa ditambah".

Aktivitas tersebut sudah difinalisasi atau sedang diverifikasi. Log hanya bisa ditambah pada aktivitas berstatus Draft.

Foto "xxx.jpg" belum dipilih, padahal sudah.

Nama di Excel harus sama dengan nama file aslinya. Penulisan huruf besar/kecil dan ekstensi tidak berpengaruh, jadi hari1 cocok dengan hari1.jpg. Kalau kolomnya berisi catatan (misalnya "Dokumentasi masing-masing"), klik tombol Pilih di kolom Bukti pada baris itu untuk memilih fotonya satu per satu.

Foto saya ada di Google Drive. Harus diunduh dulu?

Tidak perlu. Kalau sel di kolom bukti berisi link Google Drive (link folder atau file, termasuk teks yang diberi hyperlink), ekstensi mengambil fotonya otomatis. Untuk link folder, satu foto dipilih per baris, dan kamu bisa menggantinya lewat tombol Galeri. Folder harus bisa dibuka oleh akun Google yang sedang login di Chrome, atau aksesnya diatur ke "Siapa saja yang memiliki link". Kalau tidak bisa dibuka, klik Buka folder, unduh fotonya, lalu pilih lewat tombol Komputer.

Ada log yang gagal terkirim.

Pesan penyebabnya muncul di tabel. Perbaiki datanya, lalu klik Kirim ulang yang gagal. Kalau sesi login habis, login ulang, muat ulang halaman, lalu kirim lagi. Log yang sudah berhasil tidak akan dikirim dua kali.

Saya salah kirim. Bagaimana menghapusnya?

Hapus manual lewat tombol hapus di tabel Log Aktivitas Student Portal, selama aktivitasnya masih Draft.

Bisa dipakai di HP?

Bisa. Di iPhone, pakai Safari dengan aplikasi Userscripts (lihat bagian Pakai di iPhone). Di laptop atau PC, pakai ekstensi untuk Chrome, Edge, atau Brave. Android belum ada panduannya.

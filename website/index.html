Alat bantu untuk Log Aktivitas Student Portal IPB

Isi semua log aktivitas dari satu file Excel.

Tulis logbook MPKMB, kepanitiaan, atau lomba di Excel. AutoKonvert mengisinya ke Student Portal satu per satu, lengkap dengan foto bukti.

Unduh template Excel Cara pakai
  • Password tidak disimpan
  • Foto dari Google Drive
  • Laptop & iPhone

Yang perlu disiapkan

  • Aktivitas berstatus DraftDibuat dulu di menu Kemahasiswaan → Aktivitas.
  • Logbook dalam ExcelPakai template, atau spreadsheet sendiri dengan judul kolom yang dikenali.
  • Foto buktiFile di perangkat, atau link Google Drive di kolom bukti.

Cara pakai

Pemasangan cukup sekali. Setelah itu, setiap ada logbook baru kamu hanya perlu mengulang langkah 4.

  1. Buat aktivitas di Student Portal

    Log hanya bisa ditambahkan ke aktivitas yang masih berstatus Draft.

    1. Login ke studentportal.ipb.ac.id, lalu buka Kemahasiswaan → Aktivitas.
    2. Pilih Non-Kompetisi (MPKMB, pelatihan, kepanitiaan) atau Kompetisi (lomba), isi datanya, lalu Simpan Draft.

  2. Isi template Excel

    Satu baris untuk satu log. Isi di sheet Logbook; sheet Contoh dan Petunjuk tidak ikut dikirim.

    • Kolom bukti boleh berisi nama file foto (mis. hari1.jpg) atau link Google Drive.
    • Bisa diisi di Google Sheets, lalu unduh sebagai Microsoft Excel (.xlsx).
    Unduh template

  3. Pasang AutoKonvert

    Pilih perangkat yang kamu pakai.

    1. Unduh file ekstensi, klik kanan, lalu pilih Extract All. Simpan foldernya di tempat yang tidak akan dihapus, misalnya Documents.
    2. Buka Chrome, ketik chrome://extensions di kolom alamat, lalu nyalakan Developer mode di kanan atas.
    3. Klik Load unpacked dan pilih folder autokonvert-extension (yang berisi manifest.json).
    4. Klik ikon ekstensi di toolbar lalu pin AutoKonvert agar mudah ditemukan.
    Unduh ekstensi (.zip)
    Bisa juga di Microsoft Edge (edge://extensions) dan Brave. Jangan hapus atau pindahkan folder ekstensi setelah dipasang.
    1. Pasang aplikasi Userscripts dari App Store (gratis, iOS 15.1 ke atas). Buka sekali dan pilih folder penyimpanan; folder bawaan sudah cukup.
    2. Buka Pengaturan → Apps → Safari → Ekstensi (iOS 17: Pengaturan → Safari → Ekstensi), aktifkan Userscripts, lalu izinkan untuk semua situs.
    3. Buka halaman ini di Safari dan ketuk tombol di bawah. Setelah kode tampil, ketuk ikon AA di kolom alamat → Userscripts → Install.
    Pasang di iPhone
    Tombol Install tidak muncul? Tekan lama tombol di atas, pilih Unduh File Tertaut, lalu pindahkan autokonvert.user.js ke folder Userscripts lewat aplikasi Files.

  4. Kirim logbook

    1. Di Student Portal, buka Aktivitas lalu tombol Log pada aktivitas Draft.
    2. Tekan tombol AutoKonvert di kanan bawah (di iPhone: bawah layar).
    3. Pilih file Excel. Foto dari link Google Drive diambil otomatis; foto lain dipilih dari perangkat.
    4. Centang dosen penggerak, periksa pratinjau, lalu tekan Kirim.
    Log yang sudah ada di portal (tanggal, jam, dan keterangan sama) otomatis dilewati, jadi aman mengirim ulang file yang sama.

Format Excel

Urutan kolom bebas selama judulnya dikenali. Baris kosong dan baris TOTAL dilewati. Spreadsheet sendiri dengan judul seperti Deskripsi Kegiatan, Tempat Pelaksanaan, atau Dokumentasi juga bisa dipakai, begitu pula isian seperti Online, Zoom Meeting dalam satu kolom.

Pertanyaan umum

Apakah akun dan password saya aman?

Kamu login sendiri di Student Portal seperti biasa. AutoKonvert hanya memakai sesi login yang sudah ada dan mengirim data ke Student Portal, serta mengambil foto dari Google Drive jika kamu memakai link Drive. Tidak ada password atau data yang dikirim ke server lain.

Tombol AutoKonvert tidak muncul
  • Pastikan sedang membuka studentportal.ipb.ac.id (bukan halaman login), lalu muat ulang halaman.
  • Laptop: cek ekstensi aktif di chrome://extensions.
  • iPhone: pakai Safari, dan pastikan Userscripts aktif serta diizinkan untuk situs ini (ikon AA → Userscripts).
Muncul pesan "Log aktivitas ini tidak bisa ditambah"

Aktivitas itu sudah difinalisasi atau sedang diverifikasi. Log hanya bisa ditambah pada aktivitas berstatus Draft.

Foto saya ada di Google Drive

Tidak perlu diunduh. Jika sel di kolom bukti berisi link Drive (termasuk teks yang diberi hyperlink), fotonya diambil otomatis. Untuk link folder, satu foto dipilih per baris dan bisa diganti lewat tombol Galeri.

Folder harus bisa dibuka oleh akun Google yang sedang login di browser, atau aksesnya diatur ke "Siapa saja yang memiliki link". Jika tidak bisa dibuka, pilih fotonya dari perangkat.

Nama foto tidak ditemukan padahal sudah dipilih

Nama di Excel harus sama dengan nama file. Huruf besar/kecil dan ekstensi tidak berpengaruh, jadi hari1 cocok dengan hari1.jpg. Jika kolom berisi catatan (mis. "Dokumentasi masing-masing"), pilih foto per baris dari tabel pratinjau.

Ada log yang gagal atau salah kirim

Penyebab gagal tertulis di tabel pratinjau; perbaiki lalu tekan Kirim ulang yang gagal. Log yang salah kirim bisa dihapus manual dari tabel Log Aktivitas selama aktivitas masih Draft.

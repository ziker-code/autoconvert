AutoKonvert Logbook

Mengisi Log Aktivitas di Student Portal IPB dari satu file Excel. Setiap baris dikirim sebagai satu log, lengkap dengan foto bukti dari perangkat atau Google Drive.

Cocok untuk konversi MPKMB/ospek, kepanitiaan, pelatihan, dan lomba.

Template logbook.xlsx Isi satu baris untuk setiap log. Ada sheet contoh dan petunjuk.
Unduh
Ekstensi Chrome.zip Untuk laptop: Chrome, Edge, atau Brave.
Unduh
Userscript iPhone.user.js Untuk Safari di iPhone, lewat aplikasi Userscripts.
Pasang

Bekerja di browser kamu dengan sesi login Student Portal milikmu sendiri. Password tidak diminta dan tidak disimpan.

Cara pakai

Pemasangan cukup sekali. Untuk logbook berikutnya, ulangi langkah 04.

  1. Buat aktivitas berstatus Draft

    Log hanya bisa ditambahkan ke aktivitas yang belum difinalisasi.

    1. Login ke studentportal.ipb.ac.id, buka Kemahasiswaan → Aktivitas.
    2. Pilih Non-Kompetisi (MPKMB, pelatihan, kepanitiaan) atau Kompetisi (lomba), isi datanya, lalu Simpan Draft.

  2. Isi template Excel

    Isi di sheet Logbook. Sheet Contoh dan Petunjuk tidak ikut dikirim.

    • Kolom bukti berisi nama file foto (mis. hari1.jpg) atau link Google Drive.
    • Spreadsheet sendiri juga bisa dipakai, lihat Format Excel.

  3. Pasang AutoKonvert

    1. Unduh Ekstensi Chrome, klik kanan file zip, lalu Extract All. Simpan foldernya di tempat yang tidak akan dihapus.
    2. Buka chrome://extensions dan nyalakan Developer mode di kanan atas.
    3. Klik Load unpacked, pilih folder autokonvert-extension (yang berisi manifest.json).
    4. Pin ekstensi AutoKonvert dari ikon ekstensi di toolbar.
    Unduh ekstensi
    Bisa juga di Edge (edge://extensions) dan Brave. Jangan hapus atau pindahkan folder ekstensi setelah dipasang.
    1. Pasang aplikasi Userscripts dari App Store (gratis, iOS 15.1 ke atas). Buka sekali dan pilih folder penyimpanan.
    2. Buka Pengaturan → Apps → Safari → Ekstensi (iOS 17: Pengaturan → Safari → Ekstensi), aktifkan Userscripts, izinkan untuk semua situs.
    3. Di Safari, ketuk tombol di bawah. Setelah kode tampil, ketuk AA di kolom alamat → Userscripts → Install.
    Pasang di iPhone
    Tombol Install tidak muncul? Tekan lama tombol di atas, pilih Unduh File Tertaut, lalu pindahkan autokonvert.user.js ke folder Userscripts lewat aplikasi Files.

  4. Kirim logbook

    1. Di Student Portal, buka Aktivitas lalu tombol Log pada aktivitas Draft.
    2. Tekan tombol AutoKonvert di kanan bawah (di iPhone: bawah layar).
    3. Pilih file Excel. Foto dari link Google Drive diambil otomatis; foto lain dipilih dari perangkat.
    4. Centang dosen penggerak, periksa pratinjau, lalu tekan Kirim.
    Log yang sudah ada di portal (tanggal, jam, dan keterangan sama) dilewati, jadi aman mengirim ulang file yang sama.

Format Excel

Urutan kolom bebas selama judulnya dikenali. Baris kosong dan baris TOTAL dilewati. Judul seperti Deskripsi Kegiatan, Tempat Pelaksanaan, dan Dokumentasi juga dikenali, begitu pula isian Online, Zoom Meeting dalam satu kolom.

Pertanyaan

Kalau ada error, penyebabnya biasanya tertulis di tabel pratinjau.

Apakah akun dan password saya aman?

Kamu login sendiri di Student Portal seperti biasa. AutoKonvert memakai sesi login itu untuk mengirim log ke Student Portal, dan mengambil foto dari Google Drive jika kamu memakai link Drive. Tidak ada data yang dikirim ke server lain.

Tombol AutoKonvert tidak muncul
  • Pastikan sedang membuka studentportal.ipb.ac.id (bukan halaman login), lalu muat ulang halaman.
  • Laptop: cek ekstensi aktif di chrome://extensions.
  • iPhone: pakai Safari, dan pastikan Userscripts aktif serta diizinkan untuk situs ini (AA → Userscripts).
Muncul pesan "Log aktivitas ini tidak bisa ditambah"

Aktivitas itu sudah difinalisasi atau sedang diverifikasi. Log hanya bisa ditambah pada aktivitas berstatus Draft.

Foto saya ada di Google Drive

Tidak perlu diunduh. Jika sel di kolom bukti berisi link Drive (termasuk teks yang diberi hyperlink), fotonya diambil otomatis. Untuk link folder, satu foto dipilih per baris dan bisa diganti lewat tombol Galeri.

Folder harus bisa dibuka oleh akun Google yang sedang login di browser, atau aksesnya diatur ke "Siapa saja yang memiliki link". Jika tidak bisa dibuka, pilih fotonya dari perangkat.

Nama foto tidak ditemukan padahal sudah dipilih

Nama di Excel harus sama dengan nama file. Huruf besar/kecil dan ekstensi tidak berpengaruh, jadi hari1 cocok dengan hari1.jpg. Jika kolom berisi catatan (mis. "Dokumentasi masing-masing"), pilih foto per baris dari tabel pratinjau.

Ada log yang gagal atau salah kirim

Perbaiki penyebabnya lalu tekan Kirim ulang yang gagal. Log yang salah kirim bisa dihapus manual dari tabel Log Aktivitas selama aktivitas masih Draft.
